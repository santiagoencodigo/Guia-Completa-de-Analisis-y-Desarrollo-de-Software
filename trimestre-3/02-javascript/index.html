Introducción

¿Por qué aprender JavaScript?

Aprender JavaScript es fundamental para el desarrollo web moderno y para entender la lógica del lado del cliente (frontend) y cómo los navegadores interpretan y ejecutan instrucciones para crear experiencias dinámicas e interactivas. El lenguaje es versátil y universal: sirve tanto para el frontend como para el backend (mediante Node.js).

Enfoque de aprendizaje

Comenzamos con una introducción a la programación mediante ejemplos visuales y prácticos en Code.org con temática de Minecraft. Esta experiencia permitió familiarizarse con secuencias, bucles y condicionales a través de bloques, facilitando la transición a un lenguaje de texto como JavaScript.

Teoría

Conceptos clave vistos

Los pilares del lenguaje con ejemplos listos para leer y reutilizar.

Variables y tipos de datos

Se declaran con let, const y var. let tiene alcance de bloque; var, alcance de función.

let nombre = "Santiago";   // string
const edad = 25;           // number
let esActivo = true;       // boolean
let direccion = null;      // null
let telefono;              // undefined
Estructuras condicionales

Permiten tomar decisiones con if / else if / else o con switch cuando hay múltiples casos.

let edad = 18;
if (edad < 18) {
  console.log("Menor de edad");
} else if (edad >= 18 && edad < 60) {
  console.log("Adulto");
} else {
  console.log("Adulto mayor");
}
Estructuras de control (bucles)

while repite mientras la condición sea verdadera; for es ideal para recorrer rangos o arreglos.

let contador = 0;
while (contador < 5) {
  console.log("Contador: " + contador);
  contador++;
}

for (let i = 0; i < 5; i++) {
  console.log("Número: " + i);
}
Funciones

Reutilizan código y organizan la lógica. Pueden recibir parámetros y devolver valores.

function mostrarMensaje() {
  console.log("Conociendo JavaScript");
}

function sumar(a, b) { return a + b; }

const promedio = (a, b, c) => (a + b + c) / 3;
Arreglos (Arrays)

Almacenan colecciones. Se recorren con bucles y admiten métodos como push(), filter() o map().

let numeros = [10, 20, 30, 40, 50];
for (let i = 0; i < numeros.length; i++) {
  console.log(numeros[i]);
}
Captura de datos por teclado

En el navegador se usa prompt(). En Node.js existen readline y prompt-sync.

let nombre = prompt("¿Cuál es tu nombre?");
console.log("Hola, " + nombre);
Práctica

Ejercicios interactivos

Cada tarjeta describe qué demuestra el ejercicio y cómo se resuelve mediante código JS.

01
Condicionales if / else

Demuestra cómo se comparan dos valores numéricos para tomar una decisión. Con if (dinero >= precio) se evalúa la condición y, según el resultado, se ejecuta el bloque if o el else.

02
Bucles y arreglos

Con un bucle for se recorre del 1 al 10 acumulando una suma (suma += i) y llenando un arreglo. Luego, con filter(n => n % 2 === 0), se obtienen los pares.

03
Funciones con parámetros

La función evaluarNota(nota) recibe un número y devuelve un texto según el rango. Se muestra cómo una función encapsula la lógica y puede reutilizarse en cualquier parte del programa.

04
Calificación en letras switch

Estructura switch: según el valor de la nota (1 a 5) se ejecuta un case distinto. El break evita que el flujo siga evaluando los demás casos y default cubre los valores inválidos.

05
Suma del 1 al 10 con while

Bucle while que acumula la suma en la variable suma y aumenta el contador numero++ en cada iteración, hasta que la condición deja de cumplirse.

06
Números pares del 1 al 10

Combina un for con un if y el operador módulo i % 2 === 0. Si el residuo de dividir entre 2 es 0, el número es par y se agrega al resultado.

07
Arrow function · Promedio

Se usa una función flecha: const promedio = (a,b,c) => (a+b+c)/3;. Es una sintaxis corta para funciones que reciben parámetros y retornan un valor.

08
Factura · Venta hielo seco

Simulación de una factura con descuentos según el tipo de cliente (if / else if). Calcula subtotal = cantidad * valor, aplica la tasa de descuento y devuelve el valor neto a pagar.
